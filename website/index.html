More than a lucky guess

The fun is in what comes next.

A quick round is only the start. The game is built around making each run feel like progress, whether you have a minute or a longer session.

◎

Read the number

Use higher and lower feedback to narrow the range, make smarter guesses and improve your approach over time.

↗

Build your engine

Earn in-game currency and invest in upgrades, multipliers and progression systems that change how your run grows.

✦

Keep chasing goals

Streaks, achievements, challenges and longer-term progression give you more to work toward than one correct answer.

⌂

Explore beyond the run

World progression and arcade-style activities expand the game beyond the core guessing loop as those parts continue to develop.

▤

Keep your progress

Multiple save slots and recovery tools are part of the project, with game rules and save transactions handled by the Kotlin engine.

◌

Play without the noise

Designed around offline-first gameplay. No ad network, analytics tracking or account system is part of the current plan.

Built in layers

A game that grows with you.

The core loop stays simple. Around it, the project is growing a larger progression game with upgrades, challenges and worlds to work toward. Some screens and systems are still being built, so the site keeps the current status honest.
