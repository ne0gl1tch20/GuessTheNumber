Before installing an APK

Android may show an unknown-app or Play Protect warning for apps installed outside Google Play. The exact message depends on your device, the app's signing and Google's checks.

Only install a build if you trust its source and can verify what you downloaded. Start from this page or the project's official GitHub Releases page. If Android blocks the file or you cannot verify it, stop and do not install it. You do not need to turn off Play Protect to use this website.
