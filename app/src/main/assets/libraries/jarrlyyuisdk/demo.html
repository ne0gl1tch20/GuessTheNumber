Accordion and accessibility notes

Keyboard behavior
Native buttons, details, inputs and dialogs preserve expected browser keyboard behavior. Tabs and segmented controls add arrow-key navigation.
Touch targets
Primary controls aim for a minimum 44px target. Dense content may scroll horizontally instead of squeezing labels.
Reduced motion and themes
Animations respect the operating system reduced-motion preference. Use data-jui-theme="light" on the root to preview the light token set.
